# DESIGN — 設計規格（v1，規劃版）

視覺稿在 `design/mockup.html`（五個畫面、深淺色、桌機與手機）；標誌在 `design/logo/`。動工後顏色進 `src/styles/tokens.ts`，這份改為現況。

## 1. 原則

1. **心智模型照 Zoom，外觀是自己的**：底部工具列、格狀／演講者版面、右側聊天與參與者。朋友不用學。
2. **會議室預設深色**：視訊畫面在深底上好看、省眼；首頁與設定跟隨系統。
3. **狀態一眼看懂**：講話＝綠外框、靜音＝紅斜線麥克風、錄影＝紅點、分享＝藍色標籤、重連＝琥珀條。不只靠顏色，一律附圖示與文字。
4. **一次只強調一件事**：有人分享時分享是主角；沒人分享時講話者是主角。

## 3. 字體與尺寸

- 介面：`Noto Sans TC`, `PingFang TC`, `Microsoft JhengHei`, system-ui；數字用 tabular。
- 基準 16 px；名牌 13 px；工具列標籤 12 px；首頁標題 40／28 px（桌機／手機）。
- 圓角：格子 12 px、按鈕 10 px、面板 16 px；工具列按鈕 44×44（手機 48×48）。
- 間距 4 的倍數；格子間距 8 px。

## 4. 三個畫面

### 4.1 首頁 `/`

- 中央：標誌、「開著就不會斷的會議室」、兩個動作：主按鈕「開一間房」、次要「輸入連結或代碼加入」。
- 下方三個小卡：無限時、免安裝免註冊、螢幕分享與標註。
- 右上：語言、深淺色、登入（M1）。

### 4.2 預先加入 `/r/:id`（進房前）

- 左：鏡頭預覽（鏡像、4:3 或 16:9 依裝置）、底部麥克風與鏡頭開關、裝置選單。
- 右：房間名、「你的名字」輸入、「加入」主按鈕、「此房正在錄影」提示（若有）、等候室狀態（M1）。
- 手機：上下排列，預覽在上。

## 5. 元件

| 元件 | 說明 |
| --- | --- |
| `Tile` | 視訊或頭像（名字首字，顏色由名字 hash）；名牌在左下；講話外框 2 px；釘選、舉手、靜音圖示在右上 |
| `Nameplate` | 名字、靜音圖示、訊號格（3 段）、「你」標記 |
| `Toolbar` | 底部，按鈕有圖示與文字（手機只圖示）；主要狀態按鈕開＝灰底、關＝紅底白斜線 |
| `TopBar` | 房名、計時、複製連結、錄影紅點、重連琥珀條（覆蓋） |
| `SidePanel` | 聊天與參與者分頁；桌機 320 px；手機全屏抽屜 |
| `PreJoin` | 預覽 ＋ 表單 |
| `Toast` | 右上，4 秒；「<名字> 加入了」「你被主持人靜音」 |

## 6. 動態與音效

- 加入／離開：格子 200 ms 淡入縮放；重排用 CSS grid transition 200 ms。
- 反應：從格子中央浮出 5 秒，隨機微偏移。
- 音效可關：進房、離房、舉手、聊天。
- 省電模式與 `prefers-reduced-motion` 關閉全部動畫。

## 7. 品牌

- 名稱：長談 · LongTalk（待拍板，`PRD/00-prd.md` §14）。一句話：「開著就不會斷的會議室」／英文「The room that stays open.」
- 標誌：兩個對話泡泡交織成無限符號 ∞，意思是「說不完的話」。主色藍綠，深色模式自動換亮綠。檔案：`logo.svg`（圖＋字）、`logo-mark.svg`（單圖）、`favicon.svg`、`icon-maskable.svg`。
- 字標：「長談」粗體 ＋「LongTalk」細字。
