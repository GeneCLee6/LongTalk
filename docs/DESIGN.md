# DESIGN — 設計規格（v1，規劃版）

視覺稿在 `design/mockup.html`（五個畫面、深淺色、桌機與手機）；標誌在 `design/logo/`。動工後顏色進 `src/styles/tokens.ts`，這份改為現況。

## 1. 原則

1. **心智模型照 Zoom，外觀是自己的**：底部工具列、格狀／演講者版面、右側聊天與參與者。朋友不用學。
2. **會議室預設深色**：視訊畫面在深底上好看、省眼；首頁與設定跟隨系統。
3. **狀態一眼看懂**：講話＝綠外框、靜音＝紅斜線麥克風、錄影＝紅點、分享＝藍色標籤、重連＝琥珀條。不只靠顏色，一律附圖示與文字。
4. **一次只強調一件事**：有人分享時分享是主角；沒人分享時講話者是主角。

## 3. 字體與尺寸

- 介面：`Noto Sans TC`, `PingFang TC`, `Microsoft JhengHei`, system-ui；數字用 tabular。
- 基準 16 px；名牌 13 px；工具列標籤 12 px；首頁標題 40／28 px（桌機／手機）。
- 圓角：格子 12 px、名牌 8 px、按鈕 10 px、面板 16 px；工具列按鈕 44×44（手機 48×48）。
- 間距 4 的倍數；格子間距 8 px。

## 4. 三個畫面

### 4.1 首頁 `/`

- 中央：標誌、「開著就不會斷的會議室」、兩個動作：主按鈕「開一間房」、次要「輸入連結或代碼加入」。
- 下方三個小卡：無限時、免安裝免註冊、螢幕分享與標註。
- 右上：語言、深淺色、登入（M1）。

### 4.2 預先加入 `/r/:id`（進房前）

- 左：鏡頭預覽（鏡像、4:3 或 16:9 依裝置）、底部麥克風與鏡頭開關、裝置選單。
- 右：房間名、「你的名字」輸入、「加入」主按鈕、「此房正在錄影」提示（若有）、等候室狀態（M1）。
- 手機：上下排列，預覽在上。

### 4.3 會議室

```
┌──────────────────────────────────────────────┬──────────┐
│ 頂部：房名 · 00:42:13 · 複製連結    ● 錄影中  │ 側欄     │
├──────────────────────────────────────────────┤ 聊天／   │
│                                              │ 參與者   │
│   ┌───────┐ ┌───────┐ ┌───────┐              │          │
│   │ 格子  │ │ 格子  │ │ 格子  │   格狀 1–8    │          │
│   └───────┘ └───────┘ └───────┘              │          │
│   ┌───────┐ ┌───────┐ ┌───────┐              │          │
│   │       │ │       │ │       │              │          │
│   └───────┘ └───────┘ └───────┘              │          │
├──────────────────────────────────────────────┴──────────┤
│ 🎤 麥克風 ▾ │ 📷 鏡頭 ▾ │ ⬆ 分享 │ ✋ 反應 │ 💬 聊天 │ 👥 │ ⋯ │ 離開 │
└──────────────────────────────────────────────────────────┘
```

- 格狀（C1 起）：`shared/layout.ts` 的 `gridLayout` 依舞台大小選欄數（試每一種、取格子最大的），橫式舞台用 16:9 格子、直式（手機直拿）用正方形格子；最後一列置中；視窗縮放與有人進出時格子大小 200 ms 過渡。C2 起：頂部條是房名（預設「<第一位成員> 的房間」）、會議時間（從第一位成員加入起算，時:分:秒）、複製連結、右側連線狀態；工具列是麥克風、鏡頭（各帶裝置選單）、分享、聊天、參與者（人數徽章）、更多（分享連結、修改我的名字、主持人可重新命名會議室）、離開。參與者的功能在 F1，先以半透明顯示，按下提示「即將推出」（分享 D1 起、聊天 D3 起可用）；不能分享螢幕的瀏覽器（手機）不顯示分享；D2 起（`e3-t10`）「更多」第一項是灰色的「分享螢幕」，下面一行說明原因（手機：「手機瀏覽器不能分享螢幕。要分享，請用電腦加入這間會議室。」；電腦上沒有 `getDisplayMedia` 的瀏覽器：「請改用電腦上的 Chrome、Edge 或 Firefox。」），鍵盤上下鍵也停得到、螢幕閱讀器會念出說明，點了沒有作用。手機寬度只顯示圖示（完整手機版面是 C3）。
- 有分享：主區 75% 放分享（含分享者標籤），右側一列人；分享者看到簡報者檢視。D1 起（`e3-t05`、`e4-t08`）：`shared/layout.ts` 的 `shareLayout`，寬的舞台主區約 75–80%、右側一欄 16:9 的人（最寬 240 px，人多時縮小、最小 72 px 高，再多就捲動）；高的舞台（手機直拿、窄視窗）分享在上、人在下面一列（橫向捲動）；手機橫拿分享是大格、人在右側。主區不套比例，分享畫面 `object-fit: contain`（不裁切，留黑邊），左上是品牌色膠囊「<名字> 的畫面」；畫面還沒到時顯示「<名字> 開始分享畫面，馬上就來…」。**分享者自己**維持原本的版面、不顯示自己的分享（避免無限鏡像），舞台上方是「你正在分享畫面」條（品牌色淡底、紅色「停止分享」），工具列的分享鈕變成紅色「停止分享」；簡報者檢視（縮圖＋人）在 M1 的 `e3-t08`。**分享音訊**（D2，`e3-t04`）：選擇器有分享音訊時（Chrome／Edge 分享分頁，或 Windows／ChromeOS 分享整個螢幕），提示條在「停止分享」左邊多一顆次要按鈕「關閉分享音訊」（喇叭圖示）／「開啟分享音訊」（喇叭加叉），說明文字跟著換成「其他人看得到畫面、聽得到聲音；戴耳機可以避免回音」或「其他人看得到畫面，分享音訊已關閉」；沒有音訊就沒有這顆按鈕。手機寬度的提示條可以折成兩行。有人在分享時按分享先問「接手分享？」（「接手分享」有焦點，Esc／點外面＝取消）。
- **聊天**（D3，`e5-t01`、`e5-t02`）：桌機按「聊天」在舞台右側開 320 px 的側欄（`SidePanel`，標題「聊天」＋關閉鈕，Esc 也關），舞台跟著變窄、不被蓋住；手機是全螢幕抽屜（`Drawer` `full`）。訊息列由上而下：別人的靠左、灰底（`surface2`），自己的靠右、品牌淡底（`primarySoft`），上方一行小字「名字 · 21:04」（自己的寫「你」），同一人 2 分鐘內連續的訊息只在第一則寫名字；保留換行、長網址自動折行；http／https 網址是品牌色底線連結、在新分頁開。沒有訊息時置中說明「還沒有訊息…」與「訊息只留在這場會議，房間關閉後就會刪除」。下方輸入框圓角 10 px、最多長到 5 行，右側送出鈕（紙飛機，有字才變品牌色）；輸入框下一行小字「Enter 送出，Shift + Enter 換行」（觸控螢幕為主的裝置：Enter 是換行、只有送出鈕會送，小字是「按「送出」鈕傳送，Enter 換行」，鍵盤的 Enter 鍵顯示換行；2026-11-03 實測手機注音選字的 Enter 會送出半句），剩 200 字時右側倒數；送不出（太快、斷線、太長）時文字留在框裡、下方琥珀色說明。桌機打開時游標直接在輸入框；手機不自動叫出鍵盤（焦點在訊息列）。聊天沒開時：工具列「聊天」鈕右上角的品牌色徽章是未讀數（進房前就有的歷史不算），新訊息在工具列右上方跳出氣泡預覽（名字＋前兩行，約 6 秒，點了打開聊天；手機橫跨畫面寬度）。
- **離開後**（D4，`e4-t18`）：按「離開」（桌機工具列右端、手機頂部條右端）立即離開，畫面換成跟著系統深淺色的一般頁面，中央一張卡片：標誌、「你已經離開會議室」、「你離開了「<房名>」。」；分隔線下是一題「這次通話的品質如何？」與 1–5 五個方塊按鈕（下方小字：很差、不太好、普通、不錯、很好；螢幕閱讀器念「4 分：不錯」），點一下就送出、選中的變品牌色、其他變灰不能再按，下方小字從「只記分數，不記你的名字或這間會議室。」換成「謝謝你的回饋！」；不評也可以。最下方主按鈕「重新加入」（回到預先加入頁，名字與裝置是上次的，進房是新成員）與次要「回首頁」。沒有文字意見欄（PRD 只要一題）。**房間在你不在時關了**（電腦睡著、斷線超過寬限期，回來時房間已因沒人 10 分鐘而關閉）：標題改成「這間會議室已經關閉」、說明房間沒有人 10 分鐘會自動關閉，一樣可以評分，沒有「重新加入」，「回首頁」是主按鈕。從沒進去過的房間（舊分頁）照舊顯示「找不到這間會議室」。
- 標註（M2）：分享格上緣浮出工具列（筆、螢光筆、箭頭、文字、橡皮、顏色、清除）。
- 手機（C3 起，`e4-t07`）：直拿（寬 ≤ 640 px 的直式畫面）是**分頁格狀**：4 格一頁（直式舞台 2×2 正方形格子，3 人以下照格狀排），整頁左右滑（`scroll-snap`，一次一頁），下方頁點可點；桌機視窗一樣窄時頁點兩側有上一頁／下一頁，舞台取得焦點後可用方向鍵、Page Up／Down、Home／End 換頁。看不到的頁面不放視訊（顯示首字），聲音照常（每人的聲音在格子之外播放）。橫拿（高 ≤ 500 px 的橫式畫面）是**演講者**：最後講話滿 1 秒的人（不含自己）一大格，其他人在右側一欄、放不下就捲動。工具列一列五鍵：麥克風、鏡頭（各帶 ▴ 裝置選單）、聊天、參與者、更多（反應在 E5 才有，先由參與者佔位）；不顯示分享（「更多」第一項說明手機不能分享；桌機視窗窄到變成手機版面但能分享時，「分享螢幕」／「停止分享」改放在「更多」第一項）；「離開」移到頂部條右端（紅色膠囊），頂部條平常不顯示在線人數（參與者鈕有徽章），連線有問題才顯示。選單（更多、裝置）在手機改成從下方滑出的抽屜（`Drawer`）。整頁固定為可見高度（`100dvh`、不捲動），網址列出現或收起都不跳；頂部條、工具列、舞台、抽屜都讓開安全區域（`env(safe-area-inset-*)`）。判斷「手機」的媒體查詢在 `tokens.ts` 的 `media`，CSS 與 JS 共用。`prefers-reduced-motion` 時換頁直接跳、抽屜不滑動。

## 5. 元件

| 元件 | 說明 |
| --- | --- |
| `Tile` | 視訊或頭像（名字首字，顏色由名字 hash，`tokens.ts` 的 `avatar` 八色）；自己的畫面鏡像；名牌在左下；講話外框 2 px（音量門檻、熄滅防抖 300 ms，名牌同時出現聲波圖示）；重新連線中：畫面變暗、右上琥珀色「重新連線中」標籤；釘選、舉手在右上 |
| `Nameplate` | 靜音圖示或講話圖示、名字（過長省略）、「你」標記、經由轉送（自己）；訊號格（3 段）在 E2 品質統計時加 |
| `Toolbar` | 底部，按鈕有圖示與文字（手機只圖示）；主要狀態按鈕開＝灰底、關＝紅底白斜線 |
| `TopBar` | 房名、計時、複製連結、錄影紅點、重連琥珀條（覆蓋） |
| `SidePanel` | 桌機舞台右側 320 px 的面板（D3 起：聊天；F1 加參與者）；標題、關閉鈕、Esc 關閉，不是 modal；手機改用 `Drawer` `full` |
| `ChatPanel` | 聊天的訊息列與輸入框（D3），側欄與抽屜共用；`ChatPreview` 是聊天關著時的新訊息氣泡 |
| `Drawer` | 手機的抽屜（C3）：`sheet` 從下方滑出、高度隨內容（選單）；`full` 全螢幕（D3 聊天、F1 參與者）；有標題與關閉鈕，Esc、點背景關閉，Tab 留在抽屜內，關閉後焦點回原處 |
| `PreJoin` | 預覽 ＋ 表單 |
| `Toast` | 右上，4 秒；「<名字> 加入了」「你被主持人靜音」 |

## 6. 動態與音效

- 加入／離開：格子 200 ms 淡入縮放；重排用 CSS grid transition 200 ms。
- 反應：從格子中央浮出 5 秒，隨機微偏移。
- 音效可關：進房、離房、舉手、聊天。
- 省電模式與 `prefers-reduced-motion` 關閉全部動畫。

## 7. 品牌

- 名稱：**LongTalk**，只用英文，沒有中文名（2026-10-30 定案，`PRD/00-prd.md` §14）。標誌、介面、`<title>`、PWA 名稱一律寫「LongTalk」。
- 標語（標誌內）：英文「The meeting room that never cuts out」。中文介紹文案可寫「開著就不會斷的會議室」，但不和標誌組在一起。
- 標誌：兩個對話泡泡交織成無限符號 ∞，意思是「說不完的話」。主色藍綠，深色模式自動換亮綠。檔案：`logo.svg`（圖＋字）、`logo-mark.svg`（單圖）、`favicon.svg`、`icon-maskable.svg`。
- 字標：只有拉丁字「LongTalk」，粗體（700），字體 `'Inter', system-ui, sans-serif`，不需要中文字型；標語用同字體 400、次要文字色。
- 檔案（D4，`e4-t19`，`DEPLOY.md` §9）：分頁圖示是 `favicon.svg`（藍綠圓角方塊、白色標誌）加 32 px 的 `favicon.ico`；iOS 主畫面是同一張拿掉圓角的 180 px；安裝後的 App 圖示有圓角版（`any`）與滿版版（`maskable`，`icon-maskable.svg`）各 192／512 px；manifest 的名稱與短名稱都是「LongTalk」，視窗與啟動畫面用深色背景（`bg` 深色）；瀏覽器網址列顏色跟著系統深淺（`bg`）。貼連結時的預覽圖（OG image，1200×630）是藍綠底、左邊白色標誌、右邊白色粗體「LongTalk」與淡藍綠的英文標語，不放中文。全部由 `npm run brand` 從 `docs/design/logo/` 產生。
