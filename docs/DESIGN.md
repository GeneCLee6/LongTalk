# DESIGN — 設計規格（v1，規劃版）

視覺稿在 `design/mockup.html`（五個畫面、深淺色、桌機與手機）；標誌在 `design/logo/`。動工後顏色進 `src/styles/tokens.ts`，這份改為現況。G5 起，`e2e/local/__screenshots__/` 是首頁、預先加入、會議室的現況截圖（CI 比對；介面本來就要變時照 `DEPLOY.md` §7 更新基準）。

## 1. 原則

1. **心智模型照 Zoom，外觀是自己的**：底部工具列、格狀／演講者版面、右側聊天與參與者。朋友不用學。
2. **會議室預設深色**：視訊畫面在深底上好看、省眼；首頁與設定跟隨系統。
3. **狀態一眼看懂**：講話＝綠外框、靜音＝紅斜線麥克風、錄影＝紅點、分享＝藍色標籤、重連＝琥珀條。不只靠顏色，一律附圖示與文字。
4. **一次只強調一件事**：有人分享時分享是主角；沒人分享時講話者是主角。

## 3. 字體與尺寸

- 介面：`Noto Sans TC`, `PingFang TC`, `Microsoft JhengHei`, system-ui；數字用 tabular。

## 4. 三個畫面

### 4.1 首頁 `/`

- 中央：標誌、「開著就不會斷的會議室」、兩個動作：主按鈕「開一間房」、次要「輸入連結或代碼加入」。
- 下方三個小卡：無限時、免安裝免註冊、螢幕分享與標註。
- 右上：外觀（G5 起：半黑半白的圓形圖示＋選單「跟隨系統／淺色／深色」，記在 localStorage，開頁前就套用、不會閃另一種顏色；只影響一般頁面，會議室一律深色）、語言（G1 起：地球圖示＋選單，每種語言用自己的文字寫「繁體中文」「English」）、登入（M1）。預先加入頁最下面同樣有「語言」與「外觀」。
- G4 起（`e4-t12`）：「加入」下方一張安靜的卡片（白底、細框、藍綠的下載圖示）：Chromium 是粗體「安裝 LongTalk」＋一行說明＋「不用了」（文字鈕）與「安裝」（次要鈕）；iPhone／iPad Safari 是「把 LongTalk 加到主畫面」＋「在 Safari 點「分享」，再選「加入主畫面」…」＋「知道了」，只出現一次。已安裝、按過「不用了」、其他瀏覽器都不顯示；**只在首頁**。離線時動作列下方一行粗體「你目前離線。連上網路後才能開房或加入會議室。」（前面琥珀色的斷線 Wi-Fi 圖示；文字用 `fg`，琥珀色文字在淺色底對比不夠）。房間連結離線時預先加入頁換成置中的「你目前離線」（琥珀色圖示、標題、一行說明、「再試一次」），網路回來自己重試。

- G1 起（`e4-t09`）：裝置選單下方「測試喇叭」次要按鈕（喇叭圖示；播放時變「停止測試」並顯示「聽得到提示音嗎？…」），只在能選喇叭的瀏覽器出現；麥克風開著 6 秒沒聲音時音量表下方灰字提示。等候室開著時，房間資訊下方是品牌淡底的狀態卡（沙漏圖示、粗體「這間會議室開了等候室」、一行說明），主按鈕文字是「要求加入」。權限被擋時，音量表下方的提示換成**權限教學卡**（琥珀色外框）：標題「瀏覽器擋住了麥克風和鏡頭」（只擋一種時寫那一種；瀏覽器允許但系統擋住時寫「系統擋住了…」並把系統步驟放最前）、一行說明、「你的瀏覽器」選單（預設猜到的那個）、編號步驟（每步左邊一個品牌色線條圖示：網站資訊、鎖頭、開關、選單列、aA、齒輪、重新整理）、「還是不行？」系統設定一行、主按鈕「再試一次」（能自動再試時旁邊加「允許之後，這一頁會自動再試一次。」）、最後一行「也可以先不開麥克風和鏡頭直接加入…」。表單最下面是語言選單。

### 4.3 會議室

```
┌──────────────────────────────────────────────┬──────────┐
│ 頂部：房名 · 00:42:13 · 複製連結    ● 錄影中  │ 側欄     │
├──────────────────────────────────────────────┤ 聊天／   │
│                                              │ 參與者   │
│   ┌───────┐ ┌───────┐ ┌───────┐              │          │
│   │ 格子  │ │ 格子  │ │ 格子  │   格狀 1–8    │          │
│   └───────┘ └───────┘ └───────┘              │          │
│   ┌───────┐ ┌───────┐ ┌───────┐              │          │
│   │       │ │       │ │       │              │          │
│   └───────┘ └───────┘ └───────┘              │          │
├──────────────────────────────────────────────┴──────────┤
│ 🎤 麥克風 ▾ │ 📷 鏡頭 ▾ │ ⬆ 分享 │ ✋ 反應 │ 💬 聊天 │ 👥 │ ⋯ │ 離開 │
└──────────────────────────────────────────────────────────┘
```

- 格狀（C1 起）：`shared/layout.ts` 的 `gridLayout` 依舞台大小選欄數（試每一種、取格子最大的），橫式舞台用 16:9 格子、直式（手機直拿）用正方形格子；最後一列置中；視窗縮放與有人進出時格子大小 200 ms 過渡。C2 起：頂部條是房名（預設「<第一位成員> 的房間」）、會議時間（從第一位成員加入起算，時:分:秒）、複製連結、右側連線狀態；工具列是麥克風、鏡頭（各帶裝置選單）、分享、聊天、參與者（人數徽章）、更多（分享連結、修改我的名字、主持人可重新命名會議室）、離開。參與者 F1 起可用（分享 D1 起、聊天 D3 起）；不能分享螢幕的瀏覽器（手機）不顯示分享；D2 起（`e3-t10`）「更多」第一項是灰色的「分享螢幕」，下面一行說明原因（手機：「手機瀏覽器不能分享螢幕。要分享，請用電腦加入這間會議室。」；電腦上沒有 `getDisplayMedia` 的瀏覽器：「請改用電腦上的 Chrome、Edge 或 Firefox。」），鍵盤上下鍵也停得到、螢幕閱讀器會念出說明，點了沒有作用。手機寬度只顯示圖示（完整手機版面是 C3）。
- 有分享：主區 75% 放分享（含分享者標籤），右側一列人；分享者看到簡報者檢視。D1 起（`e3-t05`、`e4-t08`）：`shared/layout.ts` 的 `shareLayout`，寬的舞台主區約 75–80%、右側一欄 16:9 的人（最寬 240 px，人多時縮小、最小 72 px 高，再多就捲動）；高的舞台（手機直拿、窄視窗）分享在上、人在下面一列（橫向捲動）；手機橫拿分享是大格、人在右側。主區不套比例，分享畫面 `object-fit: contain`（不裁切，留黑邊），左上是品牌色膠囊「<名字> 的畫面」；畫面還沒到時顯示「<名字> 開始分享畫面，馬上就來…」。**分享者自己**維持原本的版面、不顯示自己的分享（避免無限鏡像），舞台上方是「你正在分享畫面」條（品牌色淡底、紅色「停止分享」），工具列的分享鈕變成紅色「停止分享」；簡報者檢視（縮圖＋人）是 H5 的 `e3-t08`（下面）。**分享音訊**（D2，`e3-t04`）：選擇器有分享音訊時（Chrome／Edge 分享分頁，或 Windows／ChromeOS 分享整個螢幕），提示條在「停止分享」左邊多一顆次要按鈕「關閉分享音訊」（喇叭圖示）／「開啟分享音訊」（喇叭加叉），說明文字跟著換成「其他人看得到畫面、聽得到聲音；戴耳機可以避免回音」或「其他人看得到畫面，分享音訊已關閉」；沒有音訊就沒有這顆按鈕。手機寬度的提示條可以折成兩行。D1 時有人在分享、按分享會先問「接手分享？」；H5 起不再問（可以同時分享）。
- **多人分享、文字／動態、簡報者檢視、防鏡像**（H5，`e3-t06`–`e3-t09`）：最多 3 人同時分享。**觀看者**：主區是最新的分享（或自己選的那個），其他分享排在側列最前面（一樣是左上品牌色「<名字> 的畫面」，整格是一顆按鈕「在主畫面看 <名字> 的畫面」，滑過時淡淡變亮）；有兩個以上別人的分享時，主區右上一排半透明深底的膠囊鈕「Bob 的畫面｜Carol 的畫面」（選中的是品牌色底），選擇記到關掉分頁為止。第四人按分享看到「已經有 3 個人在分享畫面，等其中一人停止後再試一次。」。**分享者**（簡報者檢視）：提示條最左邊是 96 × 54 的縮圖（自己分享的畫面，每秒更新一次，深色底、小圓角；螢幕閱讀器念「你分享的畫面（預覽）」），分享整個螢幕時不放縮圖，說明文字後面多一句「分享整個螢幕時不顯示預覽，以免畫面一直重複」；舞台照常是人（別人也在分享時主區是別人的分享），自己的分享永遠不會滿版。提示條上「停止分享」左邊是「文字｜動態」切換（細框白底膠囊，選中的是品牌色底；滑過顯示「清楚優先，適合文件、程式碼、投影片」／「流暢優先，適合影片、動畫」），即時生效。提示條下面需要時多一列提示（白底、左邊 4 px 色條，提示條改成大圓角的兩列）：畫面一直在動時（藍綠色條）「分享的畫面一直在動，切到「動態」會比較流暢。」＋「切到動態」（主要鈕）＋「不用」（文字鈕）；分享到會議本身時（琥珀色條，`role=alert`）「你分享的是會議室的分頁／所在的視窗，大家會看到畫面一直重複。」或「會議室就在你分享的螢幕上，大家會看到畫面一直重複。切到要給大家看的視窗，或換一個畫面。」＋「換一個畫面」（主要鈕，重新打開選擇器，選好就換、分享不中斷）＋「知道了」。
- **聊天**（D3，`e5-t01`、`e5-t02`）：桌機按「聊天」在舞台右側開 320 px 的側欄（`SidePanel`，標題「聊天」＋關閉鈕，Esc 也關），舞台跟著變窄、不被蓋住；手機是全螢幕抽屜（`Drawer` `full`）。訊息列由上而下：別人的靠左、灰底（`surface2`），自己的靠右、品牌淡底（`primarySoft`），上方一行小字「名字 · 21:04」（自己的寫「你」），同一人 2 分鐘內連續的訊息只在第一則寫名字；保留換行、長網址自動折行；http／https 網址是品牌色底線連結、在新分頁開。沒有訊息時置中說明「還沒有訊息…」與「訊息只留在這場會議，房間關閉後就會刪除」。下方輸入框圓角 10 px、最多長到 5 行，右側送出鈕（紙飛機，有字才變品牌色）；輸入框下一行小字「Enter 送出，Shift + Enter 換行」（觸控螢幕為主的裝置：Enter 是換行、只有送出鈕會送，小字是「按「送出」鈕傳送，Enter 換行」，鍵盤的 Enter 鍵顯示換行；2026-11-03 實測手機注音選字的 Enter 會送出半句），剩 200 字時右側倒數；送不出（太快、斷線、太長）時文字留在框裡、下方琥珀色說明。桌機打開時游標直接在輸入框；手機不自動叫出鍵盤（焦點在訊息列）。聊天沒開時：工具列「聊天」鈕右上角的品牌色徽章是未讀數（進房前就有的歷史不算），新訊息在工具列右上方跳出氣泡預覽（名字＋前兩行，約 6 秒，點了打開聊天；手機橫跨畫面寬度）。
- **離開後**（D4，`e4-t18`）：按「離開」（桌機工具列右端、手機頂部條右端）立即離開，畫面換成跟著系統深淺色的一般頁面，中央一張卡片：標誌、「你已經離開會議室」、「你離開了「<房名>」。」；分隔線下是一題「這次通話的品質如何？」與 1–5 五個方塊按鈕（下方小字：很差、不太好、普通、不錯、很好；螢幕閱讀器念「4 分：不錯」），點一下就送出、選中的變品牌色、其他變灰不能再按，下方小字從「只記分數，不記你的名字或這間會議室。」換成「謝謝你的回饋！」；不評也可以。最下方主按鈕「重新加入」（回到預先加入頁，名字與裝置是上次的，進房是新成員）與次要「回首頁」。沒有文字意見欄（PRD 只要一題）。**房間在你不在時關了**（電腦睡著、斷線超過寬限期，回來時房間已因沒人 10 分鐘而關閉）：標題改成「這間會議室已經關閉」、說明房間沒有人 10 分鐘會自動關閉，一樣可以評分，沒有「重新加入」，「回首頁」是主按鈕。從沒進去過的房間（舊分頁）照舊顯示「找不到這間會議室」。
- 標註（M2）：分享格上緣浮出工具列（筆、螢光筆、箭頭、文字、橡皮、顏色、清除）。
- 手機（C3 起，`e4-t07`）：直拿（寬 ≤ 640 px 的直式畫面）是**分頁格狀**：4 格一頁（直式舞台 2×2 正方形格子，3 人以下照格狀排），整頁左右滑（`scroll-snap`，一次一頁），下方頁點可點；桌機視窗一樣窄時頁點兩側有上一頁／下一頁，舞台取得焦點後可用方向鍵、Page Up／Down、Home／End 換頁。看不到的頁面不放視訊（顯示首字），聲音照常（每人的聲音在格子之外播放）。橫拿（高 ≤ 500 px 的橫式畫面）是**演講者**：最後講話滿 1 秒的人（不含自己）一大格，其他人在右側一欄、放不下就捲動。工具列一列五鍵：麥克風、鏡頭（各帶 ▴ 裝置選單）、反應、聊天、更多（C3 到 G2 由參與者佔反應的位置；G3 起參與者是「更多」的第一項（分享說明之後），聊天抽屜上方的「聊天｜參與者」也切得過去；有人在等候室時主持人的「更多」帶琥珀色人數徽章）；不顯示分享（「更多」第一項說明手機不能分享；桌機視窗窄到變成手機版面但能分享時，「分享螢幕」／「停止分享」改放在「更多」第一項）；「離開」移到頂部條右端（紅色膠囊），頂部條平常不顯示在線人數（參與者鈕有徽章），連線有問題才顯示。選單（更多、裝置）在手機改成從下方滑出的抽屜（`Drawer`）。整頁固定為可見高度（`100dvh`、不捲動），網址列出現或收起都不跳；頂部條、工具列、舞台、抽屜都讓開安全區域（`env(safe-area-inset-*)`）。判斷「手機」的媒體查詢在 `tokens.ts` 的 `media`，CSS 與 JS 共用。`prefers-reduced-motion` 時換頁直接跳、抽屜不滑動。
- **反應與舉手**（G3，`e5-t03`、`e5-t04`）：工具列「反應」（笑臉圖示，桌機在分享與聊天之間）打開一個小面板：一列六個反應 👍 ❤️ 😂 😮 👏 🎉（左右鍵可移動），下面一顆「舉手」／「放下手」（舉手時是琥珀色底）。桌機面板在工具列上方、送出後**不關**（可以連按 👏），Esc、點外面或再按一次「反應」關；手機是下方抽屜，選一個就關（看得到浮出）。舉手後工具列的圖示換成琥珀色的手（「反應（你已舉手）」），跳出「你舉手了，主持人會看到」。**浮出**：從送出者格子的中下方往上飄、淡出，5 秒，左右隨機偏一點；同一人 1.5 秒內連送同一個合成一個泡泡「👏 ×3」，一格最多 4 個泡泡；泡泡是半透明深底的膠囊，不擋按鈕（不吃點擊）。送出者的格子不在舞台上（隱藏自己、隱藏沒有視訊的人）時，舞台左下角疊一列小膠囊「名字 👍」（自己的寫「你」）。送太快（每 5 秒 8 個）跳「反應送得太快了…」。「更多 › 版面 › 隱藏表情反應」（勾選，記住）：誰的反應都不顯示。**舉手**：格子右上是琥珀色膠囊「✋ 舉手」（`warn` 底、`onWarn` 字，螢幕閱讀器念「舉手，第 N 位」）；參與者名單把舉手的人**排最上面、依舉手先後**，名字下方第一個標籤是琥珀色的「✋ N」；主持人、共同主持人的 ⋯ 選單第一項是「放下手」（只對等級比自己低、手舉著的人），對方看到「主持人 Gene 放下了你的手。」；主持人、共同主持人在有人舉手時看到「<名字> 舉手了」並有舉手音效（參與者沒有）。舉手的人講話**不會自動放下**。
- **演講者版面、釘選、聚光燈、隱藏格子**（G2，`e4-t10`、`e4-t11`）：桌機在工具列「更多」的「版面」一節選 **格狀**／**演講者**（單選，記在 localStorage，下次進房照舊）；手機照拿的方向自動決定（直拿分頁、橫拿演講者），不顯示這兩項。**演講者**：講話的人（不含自己）一大格（16:9），其他人在**下方一列**（PRD：講話者大格＋底部列；約舞台高的 24%、112–240 px，人多時縮小到 72 px 高，再多就橫向捲動）；講話滿 1 秒才算（C3），而且大格至少停在一個人身上 3 秒（`SPEAKER_SWITCH_MS`），兩個人搶話不會一直跳。**釘選**（只有自己）：滑鼠移到別人的格子上（觸控螢幕一直顯示），右上角出現圖釘鈕「釘選 <名字>」；按下後那個人進大格、格子右上是品牌色膠囊「已釘選」、跳出「已釘選 <名字>，只有你的畫面會這樣排」；不管原本是格狀還是演講者都換成演講者版面（手機直拿也是：大格在上、其他人在下面一列）；再按一次（「取消釘選 <名字>」）或「更多 › 取消釘選」回到原本的版面。自己的格子不能釘選。**聚光燈**（主持人、共同主持人，所有人）：他們看得到每個格子右上角多一顆聚光燈鈕「把 <名字> 設為聚光燈」（參與者沒有）；RoomDO 記住誰是聚光燈（一次一人，可以是自己），每個人的主區都換成演講者版面、那個人在大格，格子右上是品牌色「聚光燈」膠囊；被設為聚光燈的人跳出「你被設為聚光燈：每個人的主畫面都是你」，取消時「你的聚光燈已取消」。再按一次那顆鈕或「更多 › 取消聚光燈」結束；那個人離開或被移出時自動結束，斷線重連中保留。**先後**：自己的釘選 ＞ 聚光燈 ＞ 最後講話的人。**有人分享時**分享還是主區（`e4-t08`），被釘選或聚光燈的人排在側列第一個（在其他分享之後），不會把分享擠掉（多人分享時選主區見上面的 H5）。**隱藏自己**（勾選，記住）：自己的格子不在舞台上；只剩自己時照樣顯示。**隱藏沒有視訊的人**（勾選，只在這場會議，重新整理就恢復：記住的話下一場會議有人不見卻不知道為什麼）：別人沒開鏡頭就不顯示（自己的格子只看「隱藏自己」），被釘選或聚光燈的人照樣顯示；舞台上方一行「已隱藏 N 位沒有開視訊的人」與「全部顯示」。被隱藏的人**聲音照常**（聲音在格子之外播放），參與者名單照樣列出。

- **新版本**（G4，`e4-t12`）：左下角一張卡片（`surface` 底、左邊 4 px 藍綠色條、重新整理圖示）：「有新版本，重新整理就能使用。」，會議室裡是「有新版本。重新整理後會直接回到這場會議，也可以等會議結束再說。」；右邊「稍後」（文字鈕）與「重新整理」（主按鈕）。不是對話框、不擋畫面、不自動消失；會議室裡在工具列上方（桌機離底 96 px、手機 72 px，左右貼邊），用深色（和會議室一樣）。**從不自己重新整理**；按「稍後」後下一次換頁才套用。
- **設定與純音訊模式**（H3，`e6-t01`、`e6-t03`、`e6-t04`）：「更多」最後一節「設定」有「純音訊模式」（勾選）與「設定…」（打開 `SettingsDialog`）；預先加入頁在語言與外觀下方一顆次要按鈕「設定」（齒輪圖示）。音訊頁：麥克風、喇叭選單，「聲音處理」下三個開關（噪音抑制、回音消除、自動調整音量，瀏覽器不認得的不顯示）；視訊頁：鏡頭選單、「HD 視訊」；效能頁：「純音訊模式」。純音訊模式開著時，舞台上方中央的提示列多一則「純音訊模式：不接收也不送出視訊」＋「恢復視訊」文字鈕，所有人的格子是首字、自己的鏡頭鈕變紅（關）。**靜音中講話**：同一列出現「你目前是靜音」＋「取消靜音」＋「×」，8 秒後自己收起；螢幕閱讀器念一次。
- **鍵盤快捷鍵**（G4，`e4-t13`）：M 靜音、V 視訊、S 分享、C 聊天、P 參與者、R 舉手、L 離開（先問「要離開會議室嗎？」）、? 清單、Esc 關聊天或參與者；靜音時**按住空白鍵說話**，舞台上方中央出現「按住說話中…」小標籤（和其他提示同一列）。工具列按鈕的提示文字寫按鍵（「靜音（M）」、英文「Mute (M)」），並有 `aria-keyshortcuts`；手機版面不寫。清單是一個 modal（「鍵盤快捷鍵」標題、每列左邊一個鍵帽 `kbd`（`surface2` 底、細框、下緣 2 px）、右邊說明，最下面一行灰字「游標在輸入框（例如聊天）裡打字時，快捷鍵不會作用。」與「關閉」），從 `?` 或桌機「更多 › 鍵盤快捷鍵…」打開。

## 6. 動態與音效

- 加入／離開：格子 200 ms 淡入縮放；重排用 CSS grid transition 200 ms。
- 反應：從格子中央偏下浮出 5 秒，隨機微偏移（G3：一開始放大一下再回原大小，最後 25% 淡出）；`prefers-reduced-motion` 時不動，最新一個以靜止膠囊停在格子中下方 2.5 秒。
- 音效可關（G3，`e4-t16`，「更多 › 通知 › 音效」，記住，預設開）：進房（上行兩音）、離房（下行兩音）、舉手（三個上行音，只有主持人、共同主持人聽得到）、聊天（聊天沒開時別人傳來的訊息，短促兩音）。都是 Web Audio 現場產生的正弦／三角波，0.1–0.5 秒、音量很小，沒有音檔。房裡超過 8 人時進出不響（人數徽章照樣變）；同一種音 0.6 秒內只響一次；自己的動作不響；使用者還沒點過或按過頁面（重新整理後直接回到房間）不響，瀏覽器的 autoplay 規定也不允許。支援的瀏覽器（Chrome、Edge）從房裡選的喇叭出來。
- 省電模式與 `prefers-reduced-motion` 關閉全部動畫。

## 7. 品牌

- 名稱：**LongTalk**，只用英文，沒有中文名（2026-10-30 定案，`PRD/00-prd.md` §14）。標誌、介面、`<title>`、PWA 名稱一律寫「LongTalk」。
- 標語（標誌內）：英文「The meeting room that never cuts out」。中文介紹文案可寫「開著就不會斷的會議室」，但不和標誌組在一起。
- 標誌：兩個對話泡泡交織成無限符號 ∞，意思是「說不完的話」。主色藍綠，深色模式自動換亮綠。檔案：`logo.svg`（圖＋字）、`logo-mark.svg`（單圖）、`favicon.svg`、`icon-maskable.svg`。
- 字標：只有拉丁字「LongTalk」，粗體（700），字體 `'Inter', system-ui, sans-serif`，不需要中文字型；標語用同字體 400、次要文字色。
- 檔案（D4，`e4-t19`，`DEPLOY.md` §9）：分頁圖示是 `favicon.svg`（藍綠圓角方塊、白色標誌）加 32 px 的 `favicon.ico`；iOS 主畫面是同一張拿掉圓角的 180 px；安裝後的 App 圖示有圓角版（`any`）與滿版版（`maskable`，`icon-maskable.svg`）各 192／512 px；manifest 的名稱與短名稱都是「LongTalk」，視窗與啟動畫面用深色背景（`bg` 深色）；瀏覽器網址列顏色跟著系統深淺（`bg`）。貼連結時的預覽圖（OG image，1200×630）是藍綠底、左邊白色標誌、右邊白色粗體「LongTalk」與淡藍綠的英文標語，不放中文。全部由 `npm run brand` 從 `docs/design/logo/` 產生。
