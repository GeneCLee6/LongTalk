# ROADMAP — 開發路線圖（2026-10-28 版）

這是從零到「M3 遠端控制」的**全部順序**。一批 = 一個 PR = 一個 AI session。照批次號依序做，不跳批；每批做完在這裡把 `[ ]` 改成 `[x]` 並寫上 PR 號，同時更新 `docs/NEXT.md`「現在的位置」與 `docs/PRD/README.md` 進度表。task 的細節在 `docs/PRD/e*.md`，開工時只讀該批 task 所在的那一段。

Phase 用字母，**跳過 E 與 M**（避免和 Epic 編號 E1…E11、里程碑 M0…M3 混淆）。

**完成的定義**：
- 做完 **Phase A–D** ＝ **M0 能聊**：連結進房、SFU 音訊視訊、螢幕分享、格狀版面、聊天、重連、手機可加入、部署。和朋友開一場 > 60 分鐘不中斷就算。
- 做完 **Phase F–I** ＝ **M1 好用**：主持人控制、等候室、固定房間與日曆、版面與釘選、預先加入、反應與舉手、品質、PWA、快捷鍵、本機錄影、檔案、濫用防護、法遵。可以整個月不開 Zoom。
- 做完 **Phase J–L** ＝ **M2 超越**：標註與白板、雲端錄影與 AI 摘要、25 人與分組討論室、背景模糊、投票。
- 做完 **Phase N–O** ＝ **M3**：遠端控制、50 人、成本儀表板、多租戶。

開工指令（貼給 Claude，建議 Opus、effort medium）：

```
讀 CLAUDE.md、docs/NEXT.md、docs/ROADMAP.md。做 ROADMAP 第 <批次號> 批，照 NEXT.md 第 3 點的規則：
worktree 開分支、只讀需要的段落、lint+typecheck+test+build 只看最後 5 行、一批一個 ready PR（標題列出全部 task 編號、本文寫 AC 與檢查）、
在 PRD 勾選並更新進度表、在 ROADMAP 勾選這一批並寫 PR 號、更新 NEXT.md「現在的位置」，CI 綠了直接合併（需要人決定的事才停），合併後回報並結束。
媒體相關的 AC 要在兩台裝置實測才能勾。
```

| 時段 | 可平行 |

| I 期後 | J（標註）、K（錄影）、L1–L3（規模）三條線 |
| L 期後 | N（遠端控制）與 O1（50 人） |
