## 背景

Zoom 免費版只能本機錄影；雲端錄影與 AI Companion 都要付費。這是我們「免費做到 Zoom 付費功能」最明顯的賣點。但錄影牽涉法律與信任：**任何錄影、逐字稿、摘要都要全員看得到紅燈、進房前被告知、並能拒絕。** 同意流程寫成單獨的功能 PRD `docs/PRD/f-recording-consent.md`（`PLANNING-METHOD.md` §3），在 M2 K 期開始前完成。

M1 先做本機錄影（完全在瀏覽器，沒有伺服器成本）；M2 做雲端錄影（R2）、逐字稿、AI 摘要。

## 目標

- M1：主持人（或被允許者）可把「我看到的版面＋全員混音」錄成檔案下載；全員紅燈與提示。
- M2：雲端錄影到 R2 有下載連結與有效期；逐字稿；會後摘要、決議與待辦；自備 API 金鑰；保存與刪除政策可操作。

## 非目標

- 即時翻譯；聲紋辨識（說話者只以軌道區分）。
- 伺服器永久保存錄影（一律有有效期）。

## 需求

- 本機錄影：Canvas 以 15–30 fps 合成目前版面（格子、名牌、分享）＋ Web Audio 混音全部遠端音訊與自己的麥克風 → `MediaRecorder`（webm；Safari 用 mp4 若支援）；錄影中頂部紅燈與「<名字> 正在錄影」全員提示；進房者在預先加入看到「此房正在錄影」；錄完自動下載；長錄影分段寫入 IndexedDB 避免記憶體爆。
- 錄影權限：主持人；主持人可允許特定成員；`roles.ts`。
- 雲端錄影（M2）：ADR 決定方式（Realtime 錄製能力 vs 自架 headless 瀏覽器合成到 R2）；開始／停止由主持人；完成後 `/me` 清單有連結、有效期預設 7 天（可延長至 30）、可刪除；成本記入 E11 儀表板。
- 逐字稿（M2）：錄音（混音或各軌）送 STT 供應商（抽象介面，自備金鑰）；輸出含時間與說話者（以軌道為準）；可在 `/me` 閱讀與下載 txt／srt。
- AI 摘要（M2）：逐字稿 → 摘要、決議、待辦（含負責人若有提到）、關鍵字；模型供應商抽象，金鑰由主持人在設定輸入並只存在伺服器加密；結果貼回 `/me` 並可寄給參與者（選用）。
- 同意：啟用雲端錄影或逐字稿時全員收到提示並可「離開房間」；房間設定可預設「本房會錄影」；進房前告知。
- 保存與刪除：所有錄影／逐字稿／摘要有有效期與一鍵刪除；刪除後 R2 物件與 D1 紀錄都不存在（測試驗證）。
- 即時字幕（M2 選用）：逐字稿串流顯示在字幕區（E4 預留）。

## 設計方向

- `src/record/`：`composer.ts`（Canvas 版面合成）、`mixer.ts`（Web Audio）、`localRecorder.ts`；lazy。
- 雲端：`worker/recording.ts` 與供應商介面 `RecordingBackend`、`TranscriptionProvider`、`SummaryProvider`。
- 金鑰：Worker 以 secret 加密存 D1，只在呼叫時解密；不回傳前端。

## 驗收條件

- [ ] AC-8.1 — 本機錄影出含版面與全員混音的檔案；一小時錄影記憶體穩定；錄完自動下載；Safari 有可用格式或明確說明。
- [ ] AC-8.2 — 任何錄影／逐字稿啟用時：全員紅燈與提示、預先加入告知、可選擇離開；權限只在伺服器判斷。
- [ ] AC-8.3 — 雲端錄影到 R2；`/me` 清單、下載連結、有效期 7–30 天、刪除；成本記入儀表板。
- [ ] AC-8.4 — 逐字稿含時間與說話者；txt／srt 下載；供應商可換。
- [ ] AC-8.5 — 摘要、決議、待辦；自備金鑰加密保存；供應商可換；結果在 `/me`。
- [ ] AC-8.6 — 刪除後 R2 與 D1 皆無殘留（自動測試）；有效期到自動刪除。

## 風險與對策

| 風險 | 對策 |
